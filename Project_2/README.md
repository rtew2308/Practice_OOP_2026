## 🧪Pr_2 - Класи та об'єкти. Агрегування. Серіалізація

## 📌 Мета роботи
- Реалізувати серіалізований клас для збереження параметрів та результатів обчислень.
- Продемонструвати серіалізацію та десеріалізацію.
- Показати особливості використання transient полів.
- Обчислити двійкове представлення цілої частини кінетичної енергії.

## Задання
- Розробити клас, що серіалізується, для зберігання параметрів і результатів обчислень. Використовуючи агрегування, розробити клас для знаходження рішення задачі. 
- Розробити клас для демонстрації в діалоговому режимі збереження та відновлення стану об'єкта, використовуючи серіалізацію. Показати особливості використання transient полів. 
- Розробити клас для тестування коректності результатів обчислень та серіалізації/десеріалізації. Використовувати докладні коментарі для автоматичної генерації документації засобами javadoc.

## 📌 Основні класи

### EnergyData
- Зберігає масу, швидкість, енергію.
- Реалізує Serializable.
- Має transient поле binaryRepresentation.

### KineticEnergySolver
- Обчислює кінетичну енергію.
- Реалізує агрегування.

### SerializationDemo
- Зберігає об'єкт у файл.
- Відновлює об'єкт із файлу.

### TestRunner
- Перевіряє обчислення.
- Перевіряє серіалізацію/десеріалізацію.

## 🔎 Особливість transient

Поле `binaryRepresentation` не зберігається у файл.
Після десеріалізації воно буде null.
