##  Pr_2 - Серіалізація об'єктів та агрегування в Java

## 1. Мета роботи

1. Ознайомитися з механізмом серіалізації та десеріалізації об'єктів у Java.
2. Закріпити навички використання інтерфейсу `Serializable`.
3. Дослідити особливості застосування ключового слова `transient`.
4. Реалізувати агрегування між класами.
5. Виконати обчислення кінетичної енергії фізичного тіла та отримати її двійкове представлення.

## 2. Постановка задачі

Необхідно:

1. Розробити клас, що серіалізується, для зберігання параметрів (маси та швидкості) і результатів обчислення кінетичної енергії.
2. Використовуючи агрегування, створити клас для обчислення кінетичної енергії.
3. Реалізувати збереження та відновлення стану об’єкта за допомогою серіалізації.
4. Продемонструвати особливості використання `transient` полів.
5. Знайти двійкове представлення цілої частини значення кінетичної енергії.

## 3. Теоретичні відомості

Кінетична енергія тіла визначається за формулою:

E = (m * v²) / 2

де:
m — маса тіла,
v — швидкість руху.

Серіалізація — це процес перетворення об'єкта в потік байтів для збереження у файл або передачі мережею.

Десеріалізація — це процес відновлення об'єкта з потоку байтів.

Ключове слово `transient` використовується для виключення певних полів з процесу серіалізації.

## 4. Опис реалізації

### 4.1 Клас EnergyData

Клас реалізує інтерфейс `Serializable`.  
Призначений для зберігання:

- маси тіла;
- швидкості руху;
- значення кінетичної енергії;
- двійкового представлення (transient поле).

Поле, оголошене як `transient`, не зберігається під час серіалізації.

### 4.2 Клас EnergyCalculator

Реалізує обчислення кінетичної енергії.  
Використовує агрегування — містить посилання на об’єкт класу EnergyData.

Виконує:
- обчислення енергії;
- визначення двійкового представлення цілої частини значення.

### 4.3 Клас SerializationDemo

Забезпечує:
- запис об’єкта у файл (серіалізацію);
- відновлення об’єкта з файлу (десеріалізацію).

Використовуються класи:
- ObjectOutputStream;
- ObjectInputStream.

### 4.4 Клас TestProgram

Призначений для:
- перевірки правильності обчислень;
- демонстрації процесу серіалізації;
- демонстрації процесу десеріалізації;
- перевірки роботи transient поля.

## 5. Результати виконання

Після обчислення виводиться:
- значення кінетичної енергії;
- двійкове представлення її цілої частини.

Після десеріалізації значення transient поля дорівнює null, що підтверджує його виключення з процесу серіалізації.

## 6. Висновки

У ході виконання лабораторної роботи було:

- реалізовано серіалізацію та десеріалізацію об’єктів;
- використано агрегування між класами;
- досліджено особливості застосування ключового слова `transient`;
- виконано обчислення кінетичної енергії та отримано її двійкове представлення.

Отримані результати підтверджують коректність роботи програми та відповідність поставленому завданню.
